# oscdsh - 操作系统课程设计 Shell

## 简介

oscdsh（OS Course Design Shell）是一个使用 C 语言开发的用户态命令解释程序，作为《操作系统课程设计》实验一的成果。  
它实现了现代 Shell 的核心功能，包括命令执行、管道、重定向、后台作业管理、内置命令、历史记录、别名替换、环境变量展开、Tab 补全等，并提供彩色动态提示符与启动画面，兼具实用性与教学演示价值。

## 功能特性

### 基础命令与语法
- **外部命令执行**：`fork()` + `execvp()`，自动在 `PATH` 中搜索可执行文件
- **管道** (`|`)：支持多级管道，通过 `pipe()` + `dup2()` 连接进程间数据流，正确返回最后一个命令的退出状态
- **重定向**：
  - 输入重定向 (`<`)、输出重定向 (`> / >>`)
  - **支持带文件描述符的重定向**，如 `2> stderr.log`（stderr 重定向）、`0< input.txt`
  - 支持管道与重定向的任意组合
- **后台运行** (`&`)：父进程不阻塞，SIGCHLD 异步安全回收子进程并打印完成通知，内置 `jobs` 命令查看后台作业
- **逻辑运算符** (`&&` / `||`)：短路求值，基于命令退出状态，可与管道及重定向联合使用
- **Tab 补全**：基于 GNU Readline，行首补全命令名，参数位置补全文件名，支持路径提示

### 内置命令（12个）
| 命令 | 功能 |
|:---|:---|
| `cd [目录]` | 切换工作目录。无参数到 `HOME`；`-` 到前一目录；`HOME` 未设置时报错 |
| `type <命令>` | 判断命令类型（内置/外部）并显示路径 |
| `history [-c]` | 显示历史记录，`-c` 清空 |
| `alias [名称[=值]]` | 定义别名（支持单引号含空格的值）、查看所有别名或指定别名 |
| `unalias <名称>` | 删除别名 |
| `pwd` | 打印当前工作目录 |
| `export VAR=value` | 设置环境变量，支持同时设置多个 |
| `jobs` | 列出所有后台作业及其运行状态 |
| `true` / `false` | 返回退出状态 0 或 1，用于逻辑测试 |
| `hello` | 测试命令，打印欢迎信息 |
| `exit` | 保存历史记录并退出 Shell |
| 所有内置命令均支持 `--help` 查看用法 | |

### 交互增强
- **彩色动态提示符**：格式 `[user@host HH:MM:SS dir]$ `，各部分独立配色：
  - 用户名：亮绿加粗；主机名：蓝色；时间：青色；目录：黄色；普通用户 `$` 绿色，root 用户 `#` 红色加粗
  - 家目录自动显示为 `~`，主机名截短，时间实时更新
- **彩色启动横幅**：UTF‑8 框线 + 高亮标题，显示嵌套层级与操作提示
- **历史功能**：
  - `!!` 重复上一条命令，`!n` 执行第 n 条命令，`!?string?` 反向搜索包含 string 的命令
  - 历史持久化至 `~/.oscdsh_history`，启动自动加载，退出自动保存
  - Readline 内建历史与自定义历史完全同步，保证编号一致
- **环境变量展开**：`$VAR`、`${VAR}`、`$$`（当前 PID）、`$?`（上一条命令退出码，强制范围 0~255）
- **别名递归展开**：最多 10 层，防止死循环
- **信号处理**：`Ctrl+C` 不终止 Shell，仅影响前台子进程；`SIGTERM`/`SIGHUP` 优雅退出并保存历史

## 系统要求

- Linux 操作系统（推荐 Ubuntu 20.04+）
- GCC 编译器
- GNU Make
- GNU Readline 库（`libreadline-dev`）

安装依赖（Debian/Ubuntu）：
```bash
sudo apt install build-essential libreadline-dev
```

## 构建与安装

```bash
cd oscd/oscdsh
make
```

生成的可执行文件 `oscdsh` 位于当前目录。  
清理编译产物：`make clean`

## 使用方法

启动 Shell：
```bash
./oscdsh
```

进入后即可输入命令，示例：
```bash
ls -l | grep .c
echo hello > test.txt
cat < test.txt
sleep 10 &
jobs
alias ll='ls -l'
ll
cd /tmp && pwd || echo failed
history
exit
```

Tab 键可补全命令和文件名。

## 已知局限

- 普通命令参数不支持引号分组，含空格的参数需依赖外部脚本或转义（别名已支持单引号值）。
- 未实现作业控制命令 `fg`/`bg`、子 Shell `(cmd)` 及 `pushd`/`popd` 目录栈。
- 管道中禁止使用内置命令，逻辑运算符内的管道同样受此限制。
- 历史记录上限 1024 条，后台作业上限 64 个，别名上限 64 个。
- 仅支持标准文件描述符 0/1/2 的数字重定向。
